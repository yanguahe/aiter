## 通用命令模板

以下命令在 `hyg_fyd1` 容器的 `/data/yanguahe/code/wk_sp1/aiter` 目录执行：

```bash

  --iters 20 \
  --isa <ISA> \
  --shape 64,6144,7168 \
  --batch 96
```

## 版本说明

| 版本 | 说明 |
|---|---|
| MoE | MoE GEMM1 A4W4 load-only；独立对照，不属于 dense f4 的 v2 演进链 |
| v2 | 原始 4 operand TDM，A/B/SA/SB 各 1 wave |
| v16 | 2A+2B 拆半，双 schedule，Scale 不搬 |
| v17 | 2A+2B 拆半，单 schedule，Scale 不搬 |
| v17_v2 | wave0/2=A、wave1/3=B，单 schedule，Scale 不搬 |
| v17_v3 | hardware iterate 细化（具体以 ISA 为准） |
| v17_v4 | 4 wave 各搬完整 A，B 各 1/4 N |
| v17_v5 | 4 wave 各 1/4 M，B 各 1/4 N |
| v18 | 单 schedule，Scale 走 `global_load_b32` |
| v18_v2 | 单 schedule，Scale 走 `cluster_load_b128` |
| v19 | 单 schedule，Scale 走独立 TDM descriptor |
| v20 | 双 schedule，Scale 走独立 TDM descriptor |

## 字节口径

- MoE load-only：logical read/total 为 `2,257,747,968 B`。
- dense f4 load-only：logical read/total 为 `2,269,446,144 B`。
- 所有版本：logical write 为 `0 B`。
- TB/s 是 runner 报告的 logical/equivalent bandwidth。对 Scale 不搬版本，该数值不等价于 ISA 实际从 HBM 搬运的真实字节量，因此不能据此声称真实 HBM 流量包含完整 Scale 字节。

## 排名与结论

按三轮 median us 对 dense f4 版本排序：

```text
v17_v3 > v17 ≈ v17_v2 > v16 > v18_v2 > v18
> v19 > v20 > v2 ≈ v17_v5 > v17_v4
```

- `v17_v3` 最快，median 为 `115.0894 us`。
- `v17` 与 `v17_v2` 紧随，二者 median 仅相差 `0.0296 us`。
- `v17_v4` 最慢，median 为 `140.5232 us`。
- MoE 结果单列，不纳入以 v2 为 baseline 的 dense f4 排名和百分比比较。

## 测试健康状态

- `36/36` 次正式运行均由默认 profiler 成功采集。
- 所有结果均为 `cnt=19`、`exit=0`。
- 测试过程中未发现 hang 或 page fault。
- 测试结束后 GPU 为空闲状态，无残留测试进程。
- 状态快照中的 idle SCLK 仅描述空闲时刻，不能作为 kernel 实际运行频率；本报告不据此声称 kernel 的实际 SCLK。
